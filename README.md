# Responsive Portfolio Website

A responsive personal portfolio website built with **React**, **Vite**, **JavaScript**, **HTML**, **CSS**, and **Bootstrap**.

This project was created to showcase my software-development journey, technical skills, professional background, and selected projects through a responsive web interface.

## Live Demo

[View the live portfolio website](https://wadrien-dev.github.io/responsive-portfolio/)

## Project Overview

The Responsive Portfolio Website is a frontend project that presents my transition from healthcare operations into software development.

The website includes a landing page, project showcase, skills section, contact form layout, responsive navigation, and links to my professional profiles.

This project strengthened my experience with component-based frontend development, responsive layouts, visual design, GitHub Pages deployment, and iterative improvement.
